# X に投稿するための素材

「まちのものさし」（https://local-signal-japan.pages.dev/ ）を X で知ってもらうための素材と、投稿文の案です。
画像と動画は、公開中のサイトから `pnpm promo` で作り直せます（下の「作り直し方」）。

| `quiz/<日付>/question.png`・`answer.png` | 16:9・約16:10          | 毎日の出題と、翌日の答え（文は `quiz/README.md`）                             |

大きさは X に合わせています。

- 動画は縦長の 4:5。スマートフォンのタイムラインで大きく出て、上下が切れにくい形です（音はありません。X は音を消して自動再生するので、音なしで伝わる作りにしています）
- 画像は横長の 16:9。1枚でも、4枚まとめても、タイムラインで切れにくい形です
- 画像にはどれも出典が描き込まれています（統計ダッシュボードの利用規約で、出典の表示が必要なため）

## 告知の投稿（どれか1つを固定ポストに）

リンクは本文に入れず、返信に貼ります（本文にリンクがあると表示が伸びにくい、と言われているため）。

## 毎日のまちクイズ

日付ごとの文は `quiz/README.md` にあります。

1. 朝、その日の `question.png` を添えて出題し、返信にリンクを貼る
2. 翌朝、前日の出題を引用して、`answer.png` を添えて答えを投稿する
3. 続けて、その日の出題をする

X の投票で出すこともできます（押すだけで答えられる。画像は付けられない）。投票の文と選択肢も `quiz/README.md` にあります。

サイトの「今日の5問」と同じ問題なので、リンクを開いた人はそのまま残りの4問を解けます。結果は「🟨⬜🟨🟨🟨 4/5」の形で投稿できます。

## 投稿するときに気をつけること

- 本文は短く、数字を1つだけ。いつの値か（年・年度）は画像に入っているので、画像を付ければ出典の表示にもなる
- 特定のまちを悪く言う書き方をしない（「◯◯が少ないまち」より「◯◯が多いまち」の側から紹介する）。サイトのまちくじとクイズも、この考え方で項目を選んでいる
- ハッシュタグは1つまで（#まちくじ・#まちクイズ・#個人開発 のどれか）
- 引用や返信で「うちの町は？」と聞かれたら、まちくじの「Xに投稿」のリンク（`/m/<市区町村コード>/`）を返すと、カードにその町の札が出る

## 作り直し方

公開中のサイトを開いて、サイトの「画像で保存」と同じ画像を作ります。

```bash
pnpm promo
```

```bash
pnpm promo -- --from 2026-12-01 --days 7 --only quiz
```

- `--from` 何日からのクイズを作るか（既定は日本時間の明日）、`--days` 何日分か（既定は7）
- `--only launch|quiz|topics|profile` 一部だけ作る
- 開くサイトは環境変数 `PROMO_BASE_URL` で変えられる（既定は本番）
- 動画は Chrome の画面転送のこまをつないで作るので、ffmpeg が必要

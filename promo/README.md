# X に投稿するための素材

「まちのものさし」（https://local-signal-japan.pages.dev/ ）を X で知ってもらうための素材と、投稿文の案です。
画像と動画は、公開中のサイトから `pnpm promo` で作り直せます（下の「作り直し方」）。

## 素材の一覧

| ファイル                                 | 使いどころ                                                                          |
| ---------------------------------------- | ----------------------------------------------------------------------------------- |
| `launch/kuji.mp4`                        | 告知の動画（7秒、縦長）。トップページから「まちくじ」を引き、軽井沢町の札が出るまで |
| `launch/01-home.png`                     | スマートフォンのトップページ                                                        |
| `launch/02-kuji-karuizawa.png`           | まちくじの札（軽井沢町。空き家率が全国1位）                                         |
| `launch/03-quiz.png`                     | まちクイズの問題（11月24日の問題）                                                  |
| `launch/04-zukan.png`                    | まち図鑑（見本。富山県を制覇し、42都道府県のまちを集めた状態）                      |
| `quiz/<日付>/question.png`・`answer.png` | 毎日の出題と、翌日の答え（文は `quiz/README.md`）                                   |
| `topics/*.png`                           | 特集ランキングの画像                                                                |
| `profile/header.png`・`icon.png`         | X のプロフィールのヘッダー（1500×500）とアイコン（400×400）                         |

画像にはどれも出典が描き込まれています（統計ダッシュボードの利用規約で、出典の表示が必要なため）。

## 告知の投稿（どれか1つを固定ポストに）

リンクは本文に入れず、返信に貼ります（本文にリンクがあると表示が伸びにくい、という調査があるため）。

### A. 動画（おすすめ）

添付: `launch/kuji.mp4`

```text
全国1,741の市区町村から1つを引く「まちくじ」を作りました。
引いたまちが全国や県内で何が多い・少ないのかを、公的統計から出します。
軽井沢町を引いたら、空き家率が全国で最も高い（70.4%）と出ました。
#まちくじ
```

返信:

```text
まちくじはこちら（登録なし・無料）
https://local-signal-japan.pages.dev/#view=kuji
```

### B. 画像4枚

添付: `launch/01-home.png`、`02-kuji-karuizawa.png`、`03-quiz.png`、`04-zukan.png`

```text
公的統計で遊べるサイトを作りました。
・まちくじ：全国のまちを1つ引く
・まちクイズ：毎日0時に変わる4択が5問

```

返信:

## 毎日のまちクイズ

`quiz/README.md` に、日付ごとの出題の文・返信の文・翌日の答えの文があります。

1. 朝、その日の `question.png` を添えて出題し、返信にリンクを貼る
2. 翌朝、前日の出題を引用して、`answer.png` を添えて答えを投稿する
3. 続けて、その日の出題をする

サイトの「今日の5問」と同じ問題なので、リンクを開いた人はそのまま残りの4問を解けます。結果は「🟨⬜🟨🟨🟨 4/5」の形で投稿できます。

## 投稿するときに気をつけること

- 数字には、いつの値か（年・年度）を添える。画像には出典が入っているので、画像を付ければ出典の表示になる
- 特定のまちを悪く言う書き方をしない（「◯◯が少ないまち」より「◯◯が多いまち」の側から紹介する）。サイトのまちくじとクイズも、この考え方で項目を選んでいる
- ハッシュタグは1つまで（#まちくじ・#まちクイズ・#個人開発 のどれか）
- 引用や返信で「うちの町は？」と聞かれたら、まちくじの「Xに投稿」のリンク（`/m/<市区町村コード>/`）を返すと、カードにその町の札が出る

## 作り直し方

公開中のサイトを開いて、サイトの「画像で保存」と同じ画像を作ります。

```bash
pnpm promo
```

```bash
pnpm promo -- --from 2026-12-01 --days 7 --only quiz
```

- `--from` 何日からのクイズを作るか（既定は日本時間の明日）、`--days` 何日分か（既定は7）
- `--only launch|quiz|topics|profile` 一部だけ作る
- 開くサイトは環境変数 `PROMO_BASE_URL` で変えられる（既定は本番）

# まちのものさし（Local Signal Japan）

全国の市区町村について、公的統計（統計ダッシュボード）から作った検証済みのデータセットを読む。同梱の `scripts/lsj.mjs` で、7指標の値・基準時点・補助スコア・全国順位を取得する。

## いつ使うか

- 日本の市区町村の人口・人口増減、高齢化率、転入・転出、事業所数、完全失業率、所得、財政力を聞かれたとき。
- 「高齢化率が25%以下で、所得が400万円以上の市区町村は？」のように、数値の条件に合う市区町村を挙げるとき。
- ランキング（上位・下位）、都道府県内や人口規模別の順位、複数の市区町村の比較を求められたとき。

Web検索や記憶で答えない。条件に合う市区町村の全件と、数値の基準時点を保証できるのは、このデータセットだけ。
7指標にない項目（地価、犯罪、気候、将来推計など）は対象外。対象外だと伝え、別の手段で調べる。

## コマンド

`scripts/lsj.mjs` は、この SKILL.md があるフォルダからの相対パス。追加のインストールは要らない。出力は JSON（人に見せる表が要るときだけ `--text` を付ける）。

```bash
node scripts/lsj.mjs indicators                      # 指標キー・単位・基準時点・全国の分布（中央値など）
node scripts/lsj.mjs search 府中                      # 名前・よみがな・5桁コードで市区町村を探す
node scripts/lsj.mjs show 13101                      # 1つの市区町村の全指標（値・基準時点・補助スコア・順位・5年前比・欠損理由）
node scripts/lsj.mjs show 東京都府中市
node scripts/lsj.mjs compare 13101 横浜市青葉区 14100  # 2〜5つの市区町村を並べる
node scripts/lsj.mjs screen --where "aging<=25" --where "income>=400" --pref 東京都 --sort income --limit 0
```

### screen（条件に合う市区町村をもれなく抜き出す）

- `--where "<キー><演算子><数値>"`: 指標値の条件。演算子は `>=`（以上）と `<=`（以下）だけで、両端を含む。何度でも指定でき、すべてを満たす市区町村が残る。同じキーに両方を付けると範囲になる。数値に単位や桁区切りは付けない。
- `--sort <値>`: 並べ替えに使う値。`residents`（人口、既定）、`overall`（総合補助スコア）、指標キーのどれか。
- `--order <順>`: `desc`（大きい順、既定）か `asc`（小さい順）。
- `--pref <都道府県>`: 都道府県名（`東京都`）か2桁コード（`13`）。
- `--size <人口規模>`: `all`（既定）、`under-10k`、`10k-50k`、`50k-200k`、`over-200k`。
- `--limit <件数>`: 出力する件数。既定は20、`0` で全件。
- `--csv`: BOM付きUTF-8のCSVで出力する。

指標キー:

| キー         | 指標値                            | 単位   |
| ------------ | --------------------------------- | ------ |
| `population` | 5年間の人口増減率                 | %      |
| `aging`      | 高齢化率（65歳以上人口の割合）    | %      |
| `migration`  | 転入超過率（直近3年平均）         | %      |
| `business`   | 人口千人当たりの民営事業所数      | 事業所 |
| `employment` | 完全失業率（国勢調査）            | %      |
| `income`     | 納税義務者1人当たりの課税対象所得 | 万円   |
| `fiscal`     | 財政力指数                        | なし   |

`population` は人口そのものではなく、5年間の増減率。人口の規模で絞るには `--size`、人口の順に並べるには `--sort residents` を使う。

手順:

1. まず `--limit` を付けずに実行し、`matched`（該当数）を確かめる。
2. 全件を答えに載せるなら、`--limit 0` で取り直す。`truncated` が `true` の結果を「全件」として扱わない。
3. 該当が多いとき（目安は100件超）は、全件を会話に流し込まない。`--limit 0 --csv > 結果.csv` で保存して渡し、本文には該当数と、どの順で何件を示したかを書く。

### 市区町村の指定

5桁の市区町村コードか名前で指定する。同じ名前が複数あると（例: 府中市は東京都と広島県にある）、終了コード1で `error.code` が `ambiguous`、`error.candidates` に候補が返る。推測で選ばない。文脈で決まらなければユーザーに確かめ、コードか「都道府県名＋市区町村名」で実行し直す。

### データの場所

既定では `https://local-signal-japan.pages.dev/data/` を読む。`--data <フォルダまたはURL>` か環境変数 `LSJ_DATA` で変えられる（リポジトリの中なら `LSJ_DATA=apps/web/public/data`）。
読めないときは `error.code` が `data-unavailable`、`invalid-data`、`unsupported-schema` のどれかになる。そのときは数値を記憶や推測で補わず、取得できなかったと伝える。

## 出力の読み方

- `value` は指標値。単位は `unit`、基準時点は `period`（指標ごとに違う。`source.periods` にも入っている）。
- `score`（補助スコア）は、全国の市区町村（政令指定都市の区を除く基準集団）の中での位置を表すパーセンタイル。0〜100で、50が全国の中央。値が大きいほど高い。ただし高齢化率（`aging`）と完全失業率（`employment`）だけは、値が小さいほど高い。向きは集計上の約束で、良し悪しの判定ではない。
- `screen` と `compare` では、行の直下の `population` が住民基本台帳人口（人）、`values.population` が5年間の人口増減率（%）。取り違えない。
- `overallScore`（総合補助スコア）は、補助スコアの単純平均。4指標以上そろうときだけ算出し、足りなければ `null`。
- `rank` と `rankTotal` は、基準集団の中で値が大きい順に数えた順位（同じ値は同順位）と、その母数。良し悪しの順ではない（高齢化率の1位は、高齢化率が最も高い市区町村）。
- `screen` の `rank` は、条件で絞り込んだ中での順位。全国順位ではない。`total` は対象の数（政令指定都市の区を除き、都道府県・人口規模で絞ったあと）、`matched` は条件に合った数、`rows` はそのうち出力した分。
- `null` は欠損。「欠損」と書く。0や低い値として扱わず、平均や大小の比較にも入れない。理由は `missing` にある。
- `screen` で `rank` が `null` の行は、条件には合うが、並べ替えに使う値が欠損の市区町村。該当として数え、順位なしと書く。
- 条件を付けた指標が欠損の市区町村は、その条件に該当しない（例: 特別区は `fiscal` の条件に一切かからない）。答えに影響するときは、そのことを書く。

## 回答の必須ルール

1. 数値には必ず、指標名（`metricLabel`）・統計名（`statName`）・基準時点（`period`）を添える。例: 「高齢化率 16.2%（国勢調査、2025年）」。
2. 条件で抜き出した結果は、該当した市区町村をすべて挙げる。挙げきれないときは、該当数（`matched`）と、どの順で何件までを示したかを書く。使った条件（指標・しきい値・都道府県・人口規模・並び順）も書く。
3. データにないことを補わない。将来の見通し、原因の説明、データにない年や指標の値を推測で書かない。
4. 良し悪しを判定しない。「住みやすい」「衰退している」「おすすめ」のような評価は書かず、値と全国の中での位置だけを述べる。評価を求められたら、判断材料として値を示し、判断はユーザーに委ねる。
5. 答えの最後に、出典とクレジットを次のとおり入れる（取得日は `source.fetchedDate`）。

   > 出典: 統計ダッシュボード（https://dashboard.e-stat.go.jp/）のデータを加工して作成（データ取得日: YYYY-MM-DD）
   >
   > このサービスは、統計ダッシュボードのAPI機能を使用していますが、サービスの内容は国によって保証されたものではありません。

## 限界

- データは `source.fetchedAt`（データセットの `generatedAt`）の時点のもの。それより後に公表された値は入っていない。最新かどうかを聞かれたら、取得日と各指標の基準時点を答える。
- 指標は7つだけ。基準時点は指標ごとに違い、国勢調査に基づく指標（高齢化率、完全失業率）は5年に一度しか更新されない。
- 政令指定都市の区には全国順位がなく（`rank` は `null`）、`screen` の対象にもならない（市全体と重複するため）。所得と財政力指数は区の単位では収録されていない。区の値は `show` と `compare` で見る。
- 東京都の特別区は、財政力指数が欠損。
- 値は表示する桁に丸めてある（率は小数第1位など）。`screen` の条件は、この丸めた値と比べる。
- 過去の値は、`show` の `facts` と `change`（5年前の値、5年前比）にある範囲だけ。

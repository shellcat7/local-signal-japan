# 構成

## 全体像

```text
統計ダッシュボード API ──(pnpm data:refresh)──▶ apps/web/public/data/*.json ──(pnpm build)──▶ 静的サイト
     （総務省統計局）        packages/dataset          リポジトリに同梱                apps/web
```

- 統計の取得は、開発者の手元か GitHub Actions でだけ行います。
- 取得した結果は JSON にしてリポジトリに同梱します。
- 画面は同梱した JSON だけを読みます。閲覧時に外部の API を呼びません。

## ディレクトリ

| 場所               | 役割                                                                                                               |
| ------------------ | ------------------------------------------------------------------------------------------------------------------ |
| `packages/core`    | 指標の定義、指標値・補助スコア・順位の算出、ランキング、シグナルの文章、レポート、検索。入出力を持たない純粋な処理 |
| `packages/dataset` | 統計ダッシュボード API からの取得、データセットの組み立て・検査・読み書き（Node.js 用）                            |
| `apps/web`         | 画面（React + Vite）。`public/data/` に同梱データセット                                                            |
| `apps/cli`         | 同梱データセットを検索・表示・レポート出力する CLI                                                                 |
| `skills`           | LLM エージェント用のスキル（同梱データセットを正確に引くための手順とスクリプト）                                   |
| `e2e`              | ブラウザでの動作確認（Playwright）                                                                                 |
| `scripts`          | 秘密情報の混入検査                                                                                                 |

パッケージはビルドせず、TypeScript のソースを直接参照します（`exports` が `src/index.ts` を指しています）。

## 判断の記録

### 静的なデータセットを同梱する

閲覧時に API を呼ぶ構成（サーバーで中継する構成）にしなかった理由は次のとおりです。

- **補助スコアに全国の分布が要る。** パーセンタイルは全市区町村の値がないと計算できません。どのみち全国分をまとめて取得・計算する必要があります。
- **上流の障害や仕様変更の影響を受けない。** 統計ダッシュボード API は予告なく停止・変更されることがあると明記されています。閲覧時に依存しなければ、画面は動き続けます。
- **利用者の入力がサーバーに届かない。** サーバー側の処理がないので、検索語や閲覧履歴を記録しようがありません。
- **統計の更新頻度が低い。** 多くは年1回以下の更新です。月1回の取得で足ります。
- **再現できる。** いつ取得したどの値から画面を作ったかが、Git の履歴に残ります。

引き換えに、データセット（約3MB）をリポジトリに持つことになります。都道府県単位のファイルに分け、画面は必要な都道府県だけを読み込みます。全国を横断する画面（ランキング、全国からの比較相手の検索）は、指標値と補助スコアだけを集めた `national.json`（圧縮後 約80KB）を、その画面を開いたときに読み込みます。

### 算出ロジックを1か所に置く

指標値の算出（`computeMetric`）は `packages/core` にあり、データセットを作るときも、テストで検算するときも、同じ関数を使います。`pnpm test` は同梱データセットの全件を現在のロジックで再計算して突き合わせるので、ロジックとデータが食い違ったまま公開されることはありません。

### グラフを自前で描く

グラフは折れ線・小さな推移線・分布図・位置を示す棒・横棒だけなので、ライブラリを使わず SVG と CSS で描いています。配信するスクリプトが小さくなり、キーボード操作や読み上げ、ハイコントラスト表示への対応を細かく決められます。

### 見た目の方針

白い紙に刷った統計表と、そこに引く蛍光ペン、そして「ものさし」という考え方で組んでいます。

- 名前は「まちのものさし」。ロゴは名前の下に目盛りを引き、全国での位置を示す図も同じ目盛りつきの線にしています。
- 検索欄は、どの画面でも上部の同じ位置（名前のすぐ右）に置きます。トップページでは、開いた直後から入力できます（画面キーボードが開く端末を除く）。
- トップページの都道府県の索引は、日本地図の形に並べたます目です（狭い画面では地方ごとの一覧）。

- 面は白、文字と図の印は墨。区切りは影や囲みではなく、罫線と余白で付けます。
- 色は蛍光の黄1色だけで、「いま見ている市区町村」と「並べ替えている列」を示すのに使います。増減や順位に緑・赤を当てると良し悪しの判定に見えるため、使いません。
- 説明は見出しの下に文章で添えるのではなく、統計表と同じように表の下の「注」にまとめます。
- 位置を示す図は、端から塗る棒ではなく線の上の印にしています（塗ると「多いほど良い」と読めるため）。時系列は縦軸を途中から始めるので、面を塗らず線だけで描きます。

### くらしの指標を、補助スコアと分けて持つ

7つの指標は、全国の中での位置を補助スコアにまとめますが、くらしの指標（平均寿命、ふるさと納税など22項目）には補助スコアを付けません。高いほうがよいかどうかが項目によって分かれ、合成するとかえって誤解を招くためです。

くらしの指標は、値・全国順位に加えて、値を求めたもとの数（`basis`）をデータセットに保持します。定義と計算式は `packages/core/src/facts.ts` の1か所にあり、データセットを作るときも、テストで検算するときも、同じ計算式を使います。

### 地図を、表示用に投影して同梱する

色分け地図は、ライブラリを使わず SVG で描きます。国土数値情報の行政区域データを `scripts/build-map.mjs` で簡略化・投影し、SVG のパスの文字列として `map.json` に書き出しています。ブラウザは座標の計算をせず、パスに色を付けるだけです。地図は「地図」を選んだときにだけ読み込みます。

### 共有用の画像をブラウザで描く

ランキングや地図の画像は、canvas で描いてその場で保存します。サーバーで画像を作る仕組み（OGP 画像の動的生成など）は持ちません。表示状態は URL のハッシュに持たせているため、どのページを共有しても X などに出るカードはサイト共通の画像（`public/og.png`）です。そのぶん、保存した画像を添付して投稿する使い方にしています。

### 書体を同梱する

数字と欧文には IBM Plex Sans、市区町村コードと系列コードには IBM Plex Mono を使います（どちらも SIL Open Font License）。等幅はコードにだけ使い、時点や順位は本文と同じ書体で数字の幅だけをそろえます。ビルド時に欧文の範囲だけを同梱し、外部のフォント配信は使いません（Content-Security-Policy で外部への通信を禁止しているため）。和文は端末の標準書体で表示します。ロゴだけは、「まちのものさし」「まちくじ」の仮名8種類を収めた丸ゴシック（Zen Maru Gothic、SIL Open Font License、約1.7KB）を同梱しています。

### 表示状態を URL のハッシュに持つ

開いている画面を、次の形で URL のハッシュに持ちます。リンクとして共有でき、ハッシュはサーバーに送られないので配信元のログに残りません。ルーティングのライブラリは使っていません。

| 画面         | 例                                                               |
| ------------ | ---------------------------------------------------------------- |
| 市区町村     | `#area=13101&tab=indicators`                                     |
| 並べて比べる | `#area=16210&tab=comparison&with=13101,14100`                    |
| 条件でさがす | `#view=ranking&metric=income&pref=13&aging=..30&income=350..`    |
| 特集         | `#view=topics`、`#view=ranking&topic=bicycle&metric=commuteBike` |
| まちくじ     | `#view=kuji&area=10524&pref=10`                                  |

指標値の条件は `指標=下限..上限` の形です（片側だけでもよい）。

## 検査

| コマンド            | 内容                                                                            |
| ------------------- | ------------------------------------------------------------------------------- |
| `pnpm format:check` | 整形（Prettier）                                                                |
| `pnpm lint`         | ESLint（型情報つき）                                                            |
| `pnpm typecheck`    | TypeScript                                                                      |
| `pnpm test`         | 単体テストと、同梱データセットの検査（Vitest）                                  |
| `pnpm scan:secrets` | 秘密情報の混入検査                                                              |
| `pnpm build`        | 本番ビルド                                                                      |
| `pnpm preflight`    | 上の6つをまとめて実行                                                           |
| `pnpm test:e2e`     | ブラウザでの動作確認。操作、アクセシビリティ（axe）、横はみ出し、外部通信の有無 |

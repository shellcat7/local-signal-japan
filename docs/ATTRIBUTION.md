# Attribution

Every indicator card and generated report must include source attribution.

## Required Fields

- Source name
- Source label or source URL label
- Retrieval date
- Publication date when available
- License note
- Attribution text
- Mock-data flag

## UI Rule

Attribution must be visible near the value it supports. A global footer is not enough because users need to understand each indicator independently.

## Report Rule

Markdown reports must repeat source metadata for every indicator so exported files do not lose context.

### ふるさと納税（総務省）

> 出典：総務省「ふるさと納税に関する現況調査結果」を加工して作成

毎年8月ごろに公表される2つの Excel ファイルを使います。ファイルのアドレスは年ごとに変わるため、`pnpm data:refresh` は[案内ページ](https://www.soumu.go.jp/main_sosiki/jichi_zeisei/czaisei/czaisei_seido/furusato/archive/)のリンクの題名から探します。

| ファイル                                     | 使う列                                                                         |
| -------------------------------------------- | ------------------------------------------------------------------------------ |
| 各自治体の（年度）受入額等                   | 団体コード、受入額（円）、募集に要した費用の合計（円）                         |
| 各自治体の（年度）課税における住民税控除額等 | 団体コード、都道府県等に対する寄附金（特例控除対象）の市町村民税の控除額（円） |

見出しの位置や文言が想定と違う場合は、取得を止めます（列を取り違えたまま公開しないため）。政令指定都市の区は公表されていないため、値がありません。

### 行政区域（国土交通省）

> 地図：国土数値情報（行政区域データ）（国土交通省）を加工して作成

地図の形は `pnpm data:map`（`scripts/build-map.mjs`）で作ります（現在は2026年1月1日時点の版）。国土数値情報の行政区域データを都道府県ごとに取得し、形を簡略化し、政令指定都市の区を市にまとめ、表示用に投影（アルベルス正積図法）した座標を `apps/web/public/data/map.json` に書き出します。沖縄県・奄美群島・大東諸島・小笠原村（父島・母島）は、枠の中に移して描きます。北方領土の村、所属未定地、枠に収まらない遠くの島（硫黄島、南鳥島、沖ノ鳥島など）は描きません。市区町村の境界はめったに変わらないため、毎月の自動更新には含めていません。

## 対象の市区町村

統計ダッシュボードの地域マスタで現存している、政令指定都市・市・特別区・政令指定都市の区・町・村が対象です。統計が1つもない地域（北方領土の村）は除いています。

補助スコアの基準集団には、政令指定都市の区を含めません（[算出方法](METHODOLOGY.md)を参照）。

## 同梱データセット

取得した統計は、整形したうえでリポジトリに同梱しています（`apps/web/public/data/`）。画面はこのファイルだけを読み、閲覧時に外部の API を呼びません。

| ファイル                         | 内容                                                                                     |
| -------------------------------- | ---------------------------------------------------------------------------------------- |
| `manifest.json`                  | 取得日時、出典、指標ごとの基準年・全国の分布（度数分布を含む）・出典系列                 |
| `areas.json`                     | 検索用の市区町村一覧（コード・名前・よみがな・区分）                                     |
| `national.json`                  | 全国の市区町村の指標値・補助スコア・くらしの指標だけをまとめた一覧（ランキングと比較用） |
| `map.json`                       | 色分け地図用の、市区町村と都道府県の形（表示用に投影済み）                               |
| `pref/01.json` 〜 `pref/47.json` | 都道府県ごとの、市区町村の指標値・補助スコア・全国順位・時系列                           |

形式の定義は [`packages/core/src/schema.ts`](../packages/core/src/schema.ts) にあります。形式を変えたときは `schemaVersion` を上げます（現在は 3。くらしの指標を加えたときに上げました）。画面は、対応していない版のデータセットを読み込みません。

`national.json` は `pref/*.json` から導ける値の写しです（約320KB、圧縮後は約80KB）。ランキングや全国からの比較相手の検索のたびに47個のファイルを読まずに済むよう、別に用意しています。`pnpm test` で、両者が一致していることを全件で確かめます。

### 更新のしかた

```bash
pnpm data:refresh
```

1. 地域マスタと各系列を、統計ダッシュボード API から取得します。系列は1つにつき1リクエストで全国分を取得し、リクエストの間隔を1.5秒空けます（合計13リクエストほど）。
2. 指標値と補助スコアを計算し、形式と件数を検査します。市区町村数が極端に少ない、都道府県が47そろわない、といった取得結果は書き出さずに失敗させます。
3. `apps/web/public/data/` を書き換えます。

`pnpm test` には、同梱データセットを現在の算出ロジックで再計算して突き合わせる検査が入っています。算出方法を変えたら、データセットも作り直してください。

GitHub Actions の「データ更新」ワークフローが毎月1回これを実行し、統計値に変更があればプルリクエストを作ります。

### 取得日と基準時点

- **取得日**: API から取得した日（日本時間）。データセット全体で1つです。
- **基準時点**: その値が指している年・年度。指標ごとに異なります。

画面とレポートでは、この2つを区別して両方表示しています。

## 値の検証

各指標カードの「出典」のリンクは、その市区町村・その系列の値を返す API の URL です。同梱している値が出典と一致しているかを、誰でもその場で確かめられます。

## 収録していないもの

次の指標は、統計ダッシュボードに市区町村単位の新しい値がないため、収録していません。追加するには別の出典（多くは APIキーが必要）への対応が要ります。[ロードマップ](ROADMAP.md)を参照してください。

- 地価（市区町村単位の値は2009年まで）
- 公共調達・入札
- 法人の設立・移転

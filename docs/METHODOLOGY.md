# 算出方法

Local Signal Japan は、公開統計から読み取れることを整理して見せるための道具です。市区町村の良し悪しや将来を判定するものではありません。このページでは、画面に出る数字がどう作られているかをすべて説明します。

定義の原本はコードです。食い違いがあればコードが正で、このページを直します。

- 指標の定義と算出: [`packages/core/src/indicators.ts`](../packages/core/src/indicators.ts)
- 補助スコア・信頼度メモ: [`packages/core/src/scoring.ts`](../packages/core/src/scoring.ts)
- シグナルの文章: [`packages/core/src/signals.ts`](../packages/core/src/signals.ts)

## 指標

7つの指標を扱います。「基準年」は、その指標で全国の値がそろっている最新の年です（[データの出典](DATA_SOURCES.md)を参照）。

| 指標       | 指標値                                  | 算出                                                                              | スコアが高くなる向き |
| ---------- | --------------------------------------- | --------------------------------------------------------------------------------- | -------------------- |
| 人口       | 5年間の人口増減率（%）                  | （基準年の住民基本台帳人口 ÷ 5年前の住民基本台帳人口 − 1）× 100                   | 値が大きいほど       |
| 高齢化     | 高齢化率（%）                           | 国勢調査の「総人口に占める割合（65歳以上）」をそのまま使用                        | 値が小さいほど       |
| 転入・転出 | 転入超過率・直近3年平均（%）            | 各年の（転入者数 − 転出者数）÷ 住民基本台帳人口 × 100 を、基準年までの3年間で平均 | 値が大きいほど       |
| 事業所     | 人口千人当たりの民営事業所数            | 民営事業所数 ÷ 同じ年の住民基本台帳人口 × 1,000                                   | 値が大きいほど       |
| 雇用       | 完全失業率（%）                         | 社会・人口統計体系の「完全失業率（国勢調査）」をそのまま使用                      | 値が小さいほど       |
| 所得       | 納税義務者1人当たり課税対象所得（万円） | 課税対象所得 ÷ 納税義務者数（所得割）。千円単位を万円に換算                       | 値が大きいほど       |
| 財政       | 財政力指数                              | 社会・人口統計体系の「財政力指数（市町村財政）」をそのまま使用                    | 値が大きいほど       |

「スコアが高くなる向き」は、複数の指標を同じ目盛りに並べるための集計上の約束です。高齢化率が低いことや失業率が低いことを「良い」と評価しているわけではありません。

### 欠損の扱い

指標値を算出できないときは、0点や低い値で埋めずに「欠損」と表示し、理由を添えます。

| 理由     | 例                                                                           |
| -------- | ---------------------------------------------------------------------------- |
| 未収録   | 出典に基準年の値がない。政令指定都市の区の所得・財政、特別区の財政力指数など |
| 履歴不足 | 比較に必要な過去の値がない。区の再編直後で5年前の人口がない、など            |

## 補助スコア

補助スコアは、指標値が全国の市区町村の中でどの位置にあるかを 0〜100 で表したパーセンタイルです。

1. **基準集団**を決めます。政令指定都市の区は市全体と重複するため除き、市・特別区・町・村（指標値がある団体）を基準集団とします。
2. 基準集団の中で、その値より小さい団体の数に、同じ値の団体の数の半分を足し、団体数で割って 100 を掛けます（中間順位方式）。
3. 「値が小さいほど」の指標は `100 − パーセンタイル` に反転します。
4. 四捨五入して整数にします。

政令指定都市の区も、同じ基準集団の分布の上で位置づけます。50 が全国の中央値にあたります。

### 区分

全国を3等分して、文字で区分を示します。良し悪しを連想させる色（緑・赤）は使いません。

| 区分 | 補助スコア |
| ---- | ---------- |
| 上位 | 67 以上    |
| 中位 | 34〜66     |
| 下位 | 33 以下    |

### 総合補助スコア

利用できる指標の補助スコアの単純平均（四捨五入）です。欠損した指標は平均から除きます。利用できる指標が4つ未満のときは算出しません。

重みづけはしていません。どの指標を重く見るかは使う人の目的によって変わるため、既定で特定の見方を埋め込まないようにしています。

総合補助スコアは、この道具が独自に作った合成値です。画面では主役にせず、指標ごとの補助スコアの内訳と並べて、どう計算したかが分かる形で示します。一覧の既定の並び順も、総合補助スコアではなく人口の多い順です。

## 全国順位と分布

補助スコアとは別に、指標値そのものの全国順位と、全国の分布の中での位置を示します。

- **全国順位**: 基準集団の中で、指標値が大きい順に数えた順位です。同じ値は同順位とし、次の順位を飛ばします（1位、1位、3位）。高齢化率や完全失業率も「値が大きい順」で数えます。順位は値の大小を示すだけで、良し悪しの順ではありません。政令指定都市の区は基準集団に含まれないため、順位を付けません。
- **分布図**: 基準集団の値を28の階級に分けた度数分布です。範囲は1%点から99%点までとし、その外側の値は両端の階級に入れます（ごく少数の極端な値で図がつぶれないようにするため）。表示中の市区町村が入る階級と、全国の中央値の位置を示します。
- **全国での位置**: 概要と比較の表では、1本の線の上の印で位置を示します。左端が全国で最も値が小さい側、右端が最も大きい側、中央の縦線が中央値です。補助スコアは高齢化率・完全失業率で向きを反転していますが、この図は反転せず、値の大小のままにしています（全国順位と同じ向き）。端から塗る棒にしないのは、塗ると「多いほど良い」と読めてしまうためです。

## 5年前比

指標値に、5年前の値との差を添えます。増減率（%）で示すのは所得、差（ポイントまたは指数の差）で示すのは高齢化率・完全失業率・財政力指数です。人口は指標値そのものが5年間の増減率です。転入超過率は3年平均そのものが動きを表すため、事業所数は調査方法の変更で過去と比べられないため、5年前比を出しません。

負の数には、ハイフンではなく負号（−）を使います。

## 直近の動き

指標ごとに、決まったしきい値を超える変化があったかどうかだけを示します。差や増減率は、画面に出る値と同じ桁に丸めてからしきい値と比べます（人口が +1.0% なら「±1%を超える」には当たらず、横ばいです）。

| 指標       | 比べるもの                        | しきい値     | 表示                         |
| ---------- | --------------------------------- | ------------ | ---------------------------- |
| 人口       | 5年前の住民基本台帳人口との増減率 | ±1%          | 増加／横ばい／減少           |
| 高齢化     | 5年前の国勢調査との差             | ±0.5ポイント | 上昇／横ばい／低下           |
| 転入・転出 | 直近3年平均の転入超過率           | ±0.1%        | 転入超過／ほぼ均衡／転出超過 |
| 事業所     | 判定しない（下の注を参照）        | —            | 判定なし                     |
| 雇用       | 5年前の国勢調査との差             | ±0.3ポイント | 上昇／横ばい／低下           |
| 所得       | 5年前との増減率                   | ±2%          | 増加／横ばい／減少           |
| 財政       | 5年前との差                       | ±0.02        | 上昇／横ばい／低下           |

事業所数は、2021年の経済センサス‐活動調査で調査方法が変わったため、2016年以前の値と単純に比較できません。グラフでも線をつないでいません。

## シグナルの文章

レポートの文章と、概要タブの「読み取り時の注意」は、指標値と補助スコアから決まった規則だけで機械的に組み立てています。生成AIは使っていません。概要タブでは、表と重なる「上位の指標／下位の指標」の文章は出さず、注意と欠損だけを示します（レポートにはすべて載ります）。

- **補助スコアが上位の指標／下位の指標**: 区分が上位・下位の指標について、指標値・基準時点・全国の中での位置を1文で書きます。人口が減っていても全国の中では上位、ということがあるため、「成長」「停滞」のような方向を決めつける言葉は使わず、全国の中での位置で呼びます。
- **読み取り時の注意**: 次の条件に当てはまるときに書き出します。
  - 昼夜間人口比率が 130% 以上（昼間の流入が大きい）または 85% 以下（昼間の流出が大きい）
  - 人口が 5,000 人未満（率の指標が少数の増減で大きく動く）
  - 基準年がデータ取得年より4年以上前の指標がある
  - 政令指定都市の区である（区単位で収録されていない指標がある）
- **欠損データ**: 欠損した指標と、その理由を書きます。

## 信頼度メモ

データがどれだけそろっているかと人口規模だけで、機械的に決めています。統計の精度そのものを評価したものではありません。

| 信頼度メモ | 条件                                 |
| ---------- | ------------------------------------ |
| 高         | 7指標すべてがそろい、人口が1万人以上 |
| 中         | 5指標以上がそろい、人口が5千人以上   |
| 低         | 上のどちらにも当てはまらない         |

## 比較

### 並べて比べる

全国のどの市区町村とも、4つまで並べて比べられます。選んだ組み合わせは URL に入るので、そのまま共有できます。

追加の候補として、次の2種類を出します。

- **指標の傾向が近い**: 全国の市区町村（政令指定都市の区を除く）から、補助スコアの並び方と人口規模が近い順に選びます。距離は、共通して値のある指標の補助スコアの差の二乗平均（0〜1に換算）に、人口の常用対数の差に 0.5 を掛けたものの二乗を足し、平方根をとったものです。人口が10倍違うと、補助スコアが平均50点違うのと同じ距離になります。共通して値のある指標が5つ未満の相手は対象にしません。
- **人口規模が近い**: 同じ都道府県の中で、人口の対数の差が小さい順に選びます。

「指標の傾向が近い」は、この道具だけの目安です。総務省の「類似団体」の区分とは別のものです。

### 都道府県内での比較

同じ都道府県の中で人口規模が近い市区町村（人口の対数の差が小さい順に9団体）を初期表示します。地理的に隣り合う市区町村とは限りません。都道府県内のすべての市区町村に切り替えることもできます。

## 条件でさがす

全国の市区町村を、条件で絞り込んで並べます。条件に合う市区町村はすべて表示し、件数も示します。

- 対象は基準集団（政令指定都市の区を除く市・特別区・町・村）です。
- **指標値の範囲**: 指標ごとに下限・上限を指定できます。範囲は両端を含みます。比べるのは同梱データセットの値、つまり画面に出ている桁に丸めた値です（「30以下」は、表示が 30.0 の市区町村を含みます）。
- 条件を付けた指標が欠損の市区町村は、条件に合わないものとして扱います。並べ替えに使う値が欠損の市区町村は、条件に合っていれば、順位を付けずに末尾に並べます。
- 都道府県と人口規模（1万人未満／1万〜5万人／5万〜20万人／20万人以上）でも絞り込めます。
- 並べ替えは、人口・指標値・総合補助スコアのどれでも、値が大きい順・小さい順のどちらでもできます。既定は人口の多い順です。順位は絞り込んだ中で付け直し、同じ値は同順位にします。
- 条件は URL に入るので、そのまま共有できます。結果は CSV で保存できます（出典と取得日を末尾に付けます）。

人口の少ない市区町村では、率や1人当たりの値が少数の増減で大きく動きます。一覧には人口を必ず並べて表示しています。

トップページの「人口20万人以上の市区（上位5）」は、同じ規則で並べた抜粋です。

## くらしの指標

7つの指標とは別に、暮らしにかかわる22項目を「くらしの指標」として収録しています。値と全国順位だけを示し、補助スコア・総合補助スコアには含めません。どれも、もとの数（分子と分母など）をデータセットに保持し、自動テストで値を再計算して突き合わせています。

| 分野               | 項目                                                  | 求め方                                                                                         |
| ------------------ | ----------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 人口と暮らし       | 平均寿命（女性・男性）                                | 市区町村別生命表の0歳の平均余命                                                                |
| 人口と暮らし       | 2050年の推計人口（2025年比）                          | 将来推計人口（令和5年推計）の2050年 ÷ 2025年 − 1                                               |
| 人口と暮らし       | 外国人住民の割合                                      | 住民基本台帳の外国人住民 ÷ 住民の総数                                                          |
| 人口と暮らし       | 婚姻率・出生率（人口千人当たり）                      | 婚姻件数・出生数 ÷ 同じ年の住民基本台帳人口 × 1,000                                            |
| 人口と暮らし       | 高齢者の一人暮らし世帯の割合                          | 65歳以上の単独世帯 ÷ 一般世帯                                                                  |
| 通勤・通学         | 鉄道・電車／自家用車／自転車／徒歩だけを使う人の割合  | その手段だけを使う人 ÷ 自宅外へ通勤・通学する人（2種類以上の手段を使う人はどれにも含まれない） |
| 住まい             | 空き家率、1住宅当たりの延べ面積                       | 住宅・土地統計調査（市と人口1万5千人以上の町村だけが対象）                                     |
| 医療・図書館・ごみ | 医師・図書館の数（人口10万人当たり）                  | 医師数・図書館数 ÷ 同じ年の住民基本台帳人口 × 10万                                             |
| 医療・図書館・ごみ | 1人1日当たりのごみの量、リサイクル率                  | 一般廃棄物処理実態調査                                                                         |
| ふるさと納税       | 受入額、住民1人当たり受入額、受入額に占める費用の割合 | 総務省の現況調査。費用は返礼品・送付・広報・決済・事務・その他の合計                           |
| ふるさと納税       | 住民税の控除額、受入額と控除額の差                    | 市町村民税の控除額（都道府県等に対する寄附金・特例控除対象分）。差は受入額 − 控除額            |

読み取りの注意を、項目ごとに画面の「算出方法と注意」に書いています。主なものは次のとおりです。

- 医師の数は、医師が働いている場所で数えます。大学病院のある市区町村で多くなります。
- ごみの量は、原子力発電所の事故で避難指示が出た地域では、住民登録と実際に住む人の数が大きく違うため、極端な値になります。
- ふるさと納税の受入額は、返礼品などの費用を差し引く前の金額です。控除額の多くは、地方交付税を受けている市区町村では交付税で補われます。「受入額と控除額の差」は実際の収支ではなく目安です。
- 婚姻率・出生率・医師と図書館の数は、人口の少ない市区町村では少数の違いで大きく動きます。

## 全国で目立つところ

市区町村の概要の先頭に、その市区町村が全国の上位・下位に入っている項目を抜き出して示します。

- 対象は、7つの指標とくらしの指標です（「受入額と控除額の差」は、言い方が分かりにくくなるため除きます）。
- 政令指定都市の区を除く市区町村のうち値があるものの中で、値が大きい側・小さい側から、同じ値の市区町村も含めて10以内に収まる項目を選びます（0% のように同じ値が多数ある項目では「最も低い」と言わないため）。順位は同じ値を同順位として数えます。
- 人口の少ない市区町村で大きく動く項目（婚姻率、出生率、医師と図書館の数）は、人口1万人以上の市区町村の中だけで比べ、表示も「人口1万人以上の市区町村で」とします。人口1万人未満の市区町村では、これらの項目は抜き出しません。
- 端に近い順に、最大6項目を示します。言い方は「全国で最も高い」「全国で3番目に長い」のように、値の大小だけを表す言葉に決めています。

選び方も文章も決まった規則だけで作り、生成AIは使っていません。

## まちくじ

政令指定都市の区を除く市区町村（都道府県を指定したときはその中）から、同じ確率で1つを選び、そのまちが目立つ項目を3つまで示します。「全国で目立つところ」（上位・下位10位以内）だけでは多くの町村で何も出ないため、範囲を広げています。

- 対象の項目と比べ方（人口1万人以上どうしで比べる項目、同じ値の数え方、「受入額と控除額の差」を除くこと）は「全国で目立つところ」と同じです。
- 1つの項目からは、次のうち最初に当たるものを1つだけ選びます。
  1. 全国で上位・下位10位以内（「全国で目立つところ」と同じ）
  2. 都道府県の中で最も大きい・小さい
  3. 全国で上位・下位5%以内
  4. 都道府県の中で3位以内
- 都道府県の中の順位は、比べる市区町村が10以上ある場合だけ使います。
- ふるさと納税の受入額と住民税の控除額のような総額の項目は、多い側だけを選びます（少ない側は、人口が少ないことを言うだけになるため）。
- 並びは上の番号の順、同じ番号の中では順位の小さい順、さらに全国の端に近い順です。
- どれにも当たらない場合は、全国で端に最も近い項目を1つだけ示します。同じ値の市区町村が全体の1%を超える項目は使いません。

引いた結果は URL のハッシュ（`#view=kuji&area=10524`）に入るので、同じ札をリンクで共有できます。引いたまちの一覧は、そのページを開いている間だけ画面に残し、ブラウザには保存しません。

## 特集

決まった条件で並べた一覧に、見出しと説明を付けたものです（15本）。どれも「条件でさがす」と同じ計算で、特集から開いた一覧の条件を変えると、特集の見出しは外れます。条件は `packages/core/src/topics.ts` にあります。

## 色分け地図

「条件でさがす」の結果は、表のほかに地図でも見られます。

- 色は墨の濃淡の7段階で、値の小さい側が薄く、大きい側が濃くなります。良し悪しを連想させる色は使いません。
- 段階の境目は、条件に合う市区町村の値を件数がほぼ同じになるように分けた位置（分位）です。同じ値が多い場合は段階が減ります。
- 値のない市区町村は斜線、条件に合わない市区町村は紙の色で示します。
- 地図は補助です。同じ値は、表に切り替えて確かめられます。

## 共有用の画像

ランキング・地図・「全国で目立つところ」・まちくじの札は、出典を描き込んだ画像（PNG、1200×675）として保存できます。画像はブラウザの中で作り、どこにも送信しません。「Xに投稿」は、押したときだけ X の投稿画面を開くリンクです。

## 限界

- 補助スコアは相対的な位置です。全国的に人口が減っている局面では、人口が微減でも上位になります。必ず指標値そのものとあわせて読んでください。
- 国勢調査や経済センサスに基づく指標は、調査の間隔が長く、基準年が数年前になります。画面とレポートでは基準時点を必ず併記し、古いものは注意として挙げています。
- 人口の少ない市区町村では、率の指標が少数の増減で大きく動きます。
- 市区町村の合併や区の再編があると、過去の値と連続しないことがあります。
- 所得は名目値で、物価の変動を調整していません。納税義務者に限った平均で、住民全体の平均ではありません。
